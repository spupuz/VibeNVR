# Camera Event Providers (Event Sources)

VibeNVR supports processing motion and smart events directly from your camera's hardware. This offloads the CPU-intensive video analysis from the NVR to the camera's internal chipset, allowing you to scale up without adding expensive server hardware.

---

## ⚙️ Configuration

Event sources are configured per-camera in the **Camera Settings -> Event Sources** tab. 
*(Note: The ONVIF tab is specifically for device management, PTZ, and stream discovery. The Event Sources tab manages motion detection).*

You can choose one of the following **Detection Engines**:

### 1. Server AI / OpenCV (Default)
The VibeNVR engine pulls the RTSP stream and analyzes the video frames using standard motion detection (OpenCV) or an AI Coral TPU / CPU (MobileNet, YOLO).

### 2. ONVIF Edge (Camera-side Hardware)
VibeNVR subscribes to camera-side motion events via the **ONVIF PullPoint** service. The camera hardware decides when generic motion is occurring.
- **Prerequisite**: An ONVIF Host must be configured in the camera's ONVIF tab.
- **Behavior**: This is a binary trigger (Motion / No Motion). The timeline will show generic movement without AI labels. Local NVR exclusion zones are ignored, but Privacy Masks are still respected.

### 3. Hikvision ISAPI (Camera-side Classification)
Unlike ONVIF Edge which only detects generic movement, this specialized provider connects to the camera's HTTP API (ISAPI) to receive highly accurate, **classified AI smart events** (e.g., Person, Vehicle).
- **Prerequisite**: A Hikvision-compatible camera with ISAPI and smart event detection enabled.
- **AI Hardware Offloading**: VibeNVR automatically translates Hikvision's VMD (Video Motion Detection) events into native AI metadata. "Human/Pedestrian" becomes `person`, and "Car/Vehicle" becomes `vehicle`.
- **Zero Server Cost**: The timeline, smart filters, and notifications will display the exact AI object labels just as if VibeNVR had used a local Google Coral TPU to process the frame, providing advanced AI features with zero CPU overhead.

---

## 🛠️ Configuring Hikvision ISAPI

To configure Hikvision ISAPI:

1. Open **Camera Settings -> Event Sources**.
2. Select **Hikvision ISAPI** as the provider.
3. **ISAPI Credentials**:
   - By default, VibeNVR will attempt to reuse your existing ONVIF credentials for the ISAPI connection.
   - If your camera requires different credentials for the web/HTTP interface, select **Use separate ISAPI credentials** and enter them.
4. **Port**: Specify the HTTP port of your camera (Default: `80`). This may differ from the ONVIF port.

### Connection Diagnostics
The Event Sources tab provides an **Event Provider Status** card specifically for ISAPI. It reports:
- The connection state (e.g., "Connected", "Authentication rejected", "Timeout").
- The most recently observed labels.
- The time of the last received event.

---

## 💡 Engine Integration

VibeNVR tracks the active/inactive state of camera events and seamlessly injects them into the recording pipeline.
- All timeline object filters, AI metadata, and notifications work exactly the same regardless of whether the event was generated by Server AI, ONVIF Edge, or Hikvision ISAPI.
- VibeNVR automatically expires stale active events after 30 seconds if a disconnect occurs.
